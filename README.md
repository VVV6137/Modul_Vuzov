# Карьерный навигатор (Модуль вузов)

## Как пользоваться сайтом

1. Вкладка "Управление программами":
Здесь отображается список всех опубликованных направлений конкретного вуза. Можно публиковать новые образовательные программы: указывать название, связывать направление с профессией из каталога, задавать экзамены ЕГЭ, проходной балл и процент трудоустройства. Также можно редактировать или удалять уже созданные направления и пользоваться строкой быстрого поиска по названию или навыкам.

2. Вкладка "Аналитика и трудоустройство":
Интерактивный дашборд с двумя графиками. Столбчатая диаграмма показывает процент трудоустройства выпускников по каждому направлению подготовки, а линейный график — медианный доход специалистов, рассчитанный на основе актуальных зарплат рынка труда.

3. Вкладка "Экспресс-тест абитуриента":
Интерактивный опросник из вопросов по IT-сферам (веб-разработка, AI, кибербезопасность и т.д.). По результатам система фильтрует и рекомендует программы конкретного университета, подходящие под выбранный профиль.

4. Вкладка "Личный кабинет":
На стартовом экране представитель учебного заведения входит в систему под учетной записью своего вуза (например, НИУ ВШЭ, Бауманка или Иннополис). Доступны готовые демо-доступы (например, логин hse@edu.ru) с паролем password123.

## Стек технологий

- Frontend: HTML, CSS, Vue.js 3, Vite, Chart.js
- Backend: Node.js, Express.js
- База данных: MySQL
- Конфигурация и безопасность: dotenv, параметризованные запросы к базе (пул соединений mysql2/promise)

## Инструкция по запуску

1. Загрузка базы данных:
- Открыть MySQL Workbench
- Нажать File -> Open SQL Script и выбрать файл schema.sql из папки database
- Нажать на значок молнии (выполнить), чтобы создать базу career_navigator с таблицами и тестовыми данными

2. Настройка бэкенда (папка server):
- Перейти в папку server и создать файл .env на основе примера .env.example
- В файле .env указать свой пароль от MySQL в поле DB_PASSWORD (и проверить DB_PORT)
- Открыть терминал в папке server
- Написать команду: npm install
- Запустить сервер командой: node index.js

3. Настройка фронтенда (папка client):
- Открыть второй терминал в папке client
- Написать команду: npm install
- Запустить клиент командой: npm run dev

4. Просмотр сайта:
- Открыть браузер и перейти по локальному адресу Vite (обычно это http://localhost:5173)
